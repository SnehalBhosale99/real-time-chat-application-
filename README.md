💬 Advanced Chat App

A simple and responsive Advanced Chat Application built using HTML, CSS, and JavaScript. The project provides a clean chat interface where users can enter their name, send messages, and clear the conversation.

🚀 Features
👤 Enter and set username
💬 Send messages
📝 Display chat messages dynamically
🗑️ Clear entire chat
📱 Responsive design
🎨 Clean and modern user interface
⚡ JavaScript-based interaction
🔵 Simple blue-themed chat UI
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling, layout, colors, and responsive design
JavaScript – Chat functionality and user interaction

⚙️ How to Run

No installation or additional software is required.

1. Download or clone the project
git clone https://github.com/yourusername/Advanced-Chat-App.git
2. Open the project folder
cd Advanced-Chat-App
3. Open index.html

You can directly open index.html in any modern web browser.

🧠 JavaScript Functionality

JavaScript is used to:

Set the username
Capture user messages
Display messages in the chat area
Handle the Send button
Handle the Clear Chat button
Dynamically update the interface
🎯 Project Objective

The objective of this project is to practice frontend development using HTML, CSS, and JavaScript by creating an interactive chat application with a simple and user-friendly interface.
